FFS2PLAY

This project is a fork of the FFSTracker written in C# for FFS2 company.

FFS2PLAY will be designed on open source project model and will be writted in C++ with portable library (Qt, boost )

The core will be universal to work with P2P network for multiplayer layer Linux and mac portage will be oriented X-PLANE Windows will be compatible with P2D, FSX, FS SE and X-PLANE
