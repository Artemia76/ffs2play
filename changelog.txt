ChangeLog:

2.5.1 : Updates from the FFS2Play portal (2.5.0 was tagged but never released)
        Update check through https://ffs2play.fr (packages published on GitHub), stable or beta channel
        FFS2Play downloads the update, checks its SHA-256 and installs it : Windows installer, macOS disk image,
                 AppImage replaced in place, .deb / .rpm / Arch package through the distribution package manager
        X-Plane : the xffs2play plugin is updated too, in every X-Plane installation, once X-Plane is closed
        Linux : AppImage for every distribution, native packages for Debian, Ubuntu, Fedora, openSUSE and Arch
        "Skip this version" ; beta channel off by default
        Fixed : a newer minor version was proposed even with an older major version

2.4.3 : X-Plane CSL folders, native Linux packages
        X-Plane : CSL folders sent to the plugin as soon as the simulator is connected, and again when they change
                  in the P2P settings (the first list sent was empty)
        X-Plane : CSL folders installed in the X-Plane plugins found automatically (X-CSL-Updater, xPilot, X-IvAp,
                  LiveTraffic...) when none is configured
        X-Plane : CSL aircraft only with xffs2play 2.1.0 and later (AI mode removed from the plugin)
        Required by xffs2play 2.1.0, which no longer bundles CSL aircraft
        Linux : packaging/linux/build-package.sh builds a .deb, .rpm or Arch package for the running distribution
                against its own Qt (>= 6.8 : Debian 13, Ubuntu 25.04, Fedora 41, openSUSE Tumbleweed, Arch)
        Linux : application icon shown in the desktop menu

2.4.2 : Microsoft Flight Simulator 2024 support
        MSFS 2024 : aircraft list asked to the simulator (title and livery), no folder to configure,
                    read again at each flight ; AIs created with their livery
        MSFS 2020 / 2024 : plain ATC type and model (CESSNA, C172) sent to the peers
        MSFS 2020 : aircraft folders found automatically (UserCfg.opt)
        AI database rebuilt right after its reset
        FlightGear : peers animations (gear, flaps, lights, doors, propellers) through multiplayer properties
        Known limits : MSFS 2024 gives no ICAO type for its aircraft (no AI match by model),
                       AIs sit about 10 cm too high on the ground

2.4.1 : FlightGear support in release builds
        FlightGear : ICAO type, type and category of the aircraft from the installed aircraft (-set.xml)
        FlightGear : attitude of the aircraft, peers displayed as multiplayer aircraft
        Peers receive the type and ICAO type again when they change
        Thread safety and C++20 review (no more simulator polling thread)

2.4.0 : Migration to Qt 6 (>= 6.8) and CMake (Windows / Linux / macOS presets, CPack installers)
        Qt Protobuf replaces Google Protobuf, OpenSSL 3 replaces Crypto++
        Built-in UPnP port mapping replaces miniupnpc (no more UI freeze at startup)
        Translations and style sheet embedded in the executable
        Bug fix : encrypted data and local IP list could be truncated
        IPv6 support : portal requests and peers
        Light and dark themes
        Portal connection kept alive without simulator
        Bug fix : user profiles lost on restart
